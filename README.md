# Agent Skills

A collection of reusable skills for development workflows. Installable via the [`skills` CLI](https://github.com/vercel-labs/skills).

| Name                  | Description                                                                                                             | Install                                    |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| `bc-grill-me`         | Get relentlessly interviewed about a plan or design until every branch of the decision tree is resolved.                | [Install](./bc-grill-me/README.md)         |
| `bc-issue-to-plan`    | Create a concrete implementation plan from a GitHub issue, exploring the codebase to identify files and changes needed. | [Install](./bc-issue-to-plan/README.md)    |
| `bc-prd-to-issues`    | Break a PRD into independently-grabbable GitHub issues using tracer-bullet vertical slices.                             | [Install](./bc-prd-to-issues/README.md)    |
| `bc-todo`             | Create a structured TODO.md with Bugs, Features, and Chores sections.                                                   | [Install](./bc-todo/README.md)             |
| `bc-write-case-study` | Generate a polished case study blog post from a code repository.                                                        | [Install](./bc-write-case-study/README.md) |
| `bc-write-prd`        | Create a PRD through user interview, codebase exploration, and module design, then submit as a GitHub issue.            | [Install](./bc-write-prd/README.md)        |
